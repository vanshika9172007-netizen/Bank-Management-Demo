# Bank-Management-Demo
Bank Management System
<br>
A Java-based console application connected to MySQL using JDBC.

Features

Open account
<br>
Deposit money
<br>
Withdraw money
<br>
Search account
<br>
Display account records
<br>
Close account


Technologies

Java
<br>
MySQL
<br>
JDBC

How to run

Create the MySQL database.
<br>
Create the required bankrecord table.
<br>
Update the database credentials locally.
<br>
Compile and run BankRecord.java.
